Your first network in four pieces

The core loop is deliberately simple: create a root, connect storage, add an interface, then automate around it.

01
⌘

Place a Controller

The Controller is the root of a connected Networks system. Build outward from it with valid network nodes.

02
▦

Add storage

Use Cells, Quantum Storage, Drawers, or supported storage adapters to make items available to the network.

03
▤

Open a Grid

Grids provide a clean inventory view of network contents. Crafting Grids add recipe assembly directly on top.

04
⇄

Move & automate

Pushers, Grabbers, Importers, Exporters, wireless nodes, and Expansion transfer machines handle the rest.
