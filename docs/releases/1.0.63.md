# SF_Networks 1.0.63 — Metadata Safety and Universal Build Maintenance

This is a **new version candidate**, following the immutable published 1.0.62 artifact. It retains the Java-only universal plugin baseline for Minecraft **1.21.11+**, including Paper/Purpur support. This document does not assert that the candidate is published or ready to deploy.

## Changes since 1.0.62

- Compare tropical-fish bucket metadata only when corresponding variants are present, preventing an absent component from being read as if it existed. Preserve distinguishable present/absent states; dedicated TropicalFishMetadataComparisonTest and ItemDifferenterTropicalFishTest regressions cover the handling.
- Use the verified Gradle 9.8.2 wrapper and its official distribution checksum in build tooling. The source patch does **not** change the Java 21 distributable bytecode target.
- Add source-only, fail-closed comparative Auto Crafter profiler receipts rather than claiming performance gains from unmatched samples.

No network/storage identities, item IDs, research IDs, recipes, amounts, transfer rates, energy consumption, saved metadata formats, persistent keys, inventory ordering, or recovery policy are intentionally changed.

## Required checks before publication

The exact **1.0.63** commit must pass the three-core Legacy/United/GuGu compatibility matrix, strict 1.21.11 compiler tests, Java 21 bytecode and unshaded dependency identity checks, and Paper 26.3 advisory API compilation. It must also retain successful native manager/Quantum tests and independent restarts on Purpur 1.21.11 and Paper 26.3 builds 176 and 194, plus the relevant source-pinned Slimefun Legacy bundle and storage integration checks. Leaf/Folia region ownership and historical-world rollback are not established by compiler success.

Only publish a **new** v1.0.63 tag and SF_Networks1.0.63.jar after passing the applicable exact-source and exact-byte gates. The released 1.0.62 JAR and existing assets must remain byte-for-byte unchanged.

## Installation (after a validated release)

Stop the server; back up worlds, plugin configuration and network storage data; install the validated raw JAR, and perform a clean restart. Do not use /reload. Retain the prior artifact and corresponding backups for planned rollback. No cross-fork rollback certification or measured TPS/MSPT improvement is claimed.
