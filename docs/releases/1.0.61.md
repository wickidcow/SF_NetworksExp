# SF_Networks 1.0.61 — Transfer Ticker Performance Maintenance

Networks 1.0.61 is a compatibility-preserving update distributed as the **universal `SF_Networks1.0.61.jar`** for Minecraft **1.21.11+**. It carries forward the storage safety repairs released in Networks 1.0.60 and is compatible with Slimefun Legacy 4.1.76 and InfinityExpansion2 2.0.15.

## Changes

- Remove unnecessary `LAST_TRANSFER_SERVER_TICK` map updates, boxed server tick values and `Bukkit.getCurrentTick()` calls from every `AbstractTransfer` ticker callback. All three supported Slimefun core implementations register a single active `BlockTicker.class` handler per item; AdvancedDirectional's later ticker replaces its inherited handler instead of executing twice.
- Add an exact-source invariant check to all three-core compatibility lanes. If a future Slimefun fork changes BlockTicker handler registration, the build refuses to publish.
- Preserve all existing transfer modes, P2P slot routing, template order, source/destination priorities, energy/quantity costs, machine timing, Drawer/Quantum/IE2 storage identities, backup/rollback receipts, all 289 item IDs and persisted formats. No data migration is required.

## Validation and limitations

The release workflow requires successful Legacy/United/GuGu builds, Java 21 universal-JAR checks, Paper 26.3 API compilation, Purpur 1.21.11 native manager/viewer tests, and Paper 26.3 builds 176 and 194 with independent-process Quantum Storage persistence checks. Only the artifact from the successful exact-source workflow is eligible for publication.

**The change reduces redundant bookkeeping. It has not been shown to yield a specific TPS/MSPT improvement on a loaded server.** Compare fresh profiler samples using the same 128-machine topology before claiming an improvement. Cross-region Folia support remains unverified and is not enabled.

## Installation

Stop your server, back up Networks databases and player/world data, remove the previous Networks JAR and place `SF_Networks1.0.61.jar` inside `plugins/`. Restart normally, never `/reload`. The former Networks 1.0.60 asset remains available unchanged for deliberate rollback using matching backups.
