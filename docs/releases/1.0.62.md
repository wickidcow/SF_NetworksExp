# SF_Networks 1.0.62 — Item-Conservation and Transfer Maintenance

Networks 1.0.62 is a compatibility-preserving update distributed as the universal `SF_Networks1.0.62.jar` for Minecraft **1.21.11+**. It builds on the storage safety and ticker performance work in 1.0.61 and is intended for Slimefun Legacy, United and Gugu.

## Changes

- **Persist item merges reliably:** `BlockMenuUtil.pushItem` now explicitly commits successful existing-slot merges, including inventories whose slot reads return detached item copies, instead of reporting items accepted without updating the destination. The implementation retains no-callback merge behavior, exact source decrement and partial-remainder semantics while avoiding duplicate dirty bookkeeping.
- **One-pass specified-quantity transfers:** Networks Expansion line pushers using `SPECIFIED_QUANTITY` now compute existing matching item counts and destination free capacity in one traversal. Preserve exact withdrawal limits, output receipts and rollback protection.
- Extend Mockito/unit regressions for detached-slot merges, multiple partial stacks, already-full slots, preserved item counts and bounded `SPECIFIED_QUANTITY` requests.

These changes **do not** alter network item IDs, blueprints, recipes, machine speeds, tick schedules, storage databases or serialized formats. No migration is required.

## Validation

The release workflow must pass exact-source universal Java 21 builds, the three-core Legacy/United/Gugu test matrix, Paper 26.3 Java 25 API compilation, Purpur 1.21.11 native storage persistence checks and two independent native Paper 26.3 runtime/storage probes (builds 176 and 194). Its official release job may publish only after every required dependency completes successfully.

A production sample measured **400 `NTW_AUTO_CRAFTER` calls totaling 32.31 ms** across ten Slimefun ticker intervals. Existing idle backoff and batched ingredient availability were preserved rather than speculatively rewritten. The separate 13 line-pusher calls totaled 4.46 ms; the one-pass improvement affects only the configured specified-quantity mode. **No TPS/MSPT improvement is claimed without a matched post-upgrade sample.**

## Installation

Stop your server and back up the Networks storage database, worlds and plugin configuration. Replace the prior Networks JAR with `SF_Networks1.0.62.jar` and restart normally; do not use `/reload`. Retain the published 1.0.61 artifact and matching backups for deliberate rollback.

This is a Java/Paper-family addon release. It does not alter the optional resource-pack directory or introduce Geyser/Bedrock integration.
